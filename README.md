# 🎓 Student Management System

A console-based Student Management System built using Java, JDBC, and Oracle SQL.

## 🚀 Features
- Add Student
- View All Students
- Search Student by ID
- Update Student
- Delete Student

## 🛠️ Tech Stack
- Java (Core Java)
- JDBC
- Oracle SQL

## 📂 Project Structure
src/
 ├── model
 ├── dao
 ├── util
 └── app

## 🧠 Concepts Used
- OOP (Encapsulation)
- JDBC (PreparedStatement, ResultSet)
- SQL (CRUD Operations)
